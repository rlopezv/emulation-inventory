# Prompt - Review distributions.md

Revisa `docs/distributions.md` aplicando estas reglas:

1. Cada dispositivo de `docs/devices.md` debe tener una fila propia.
2. No sustituyas dispositivos por familias agregadas.
3. Valida que el software recomendado exista en `docs/software.md`, salvo si está marcado como `[TODO]` o explicado en notas.
4. Mantén la cabecera exacta de la tabla principal.
5. Usa `Desconocido` para instalación real no confirmada.
6. No añadas resumen ejecutivo ni tareas pendientes.
7. Conserva Koriki como alternativa relevante cuando aplique.
8. No trates RG35XX original como familia H700 moderna.
