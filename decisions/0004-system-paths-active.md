# 0004 - system-paths.md pasa a activo

## Decisión

`docs/system-paths.md` deja de considerarse pendiente de definición. Su estructura (matriz CFW × sistema con rutas de ROMs, BIOS, saves, states, media y `gamelist.xml`) ya está definida y poblada para varios CFW (ROCKNIX, KNULLI, entre otros). Se puede seguir extendiendo con nuevos CFW siguiendo el formato de tabla existente.

Esta decisión sustituye a [0003](0003-system-paths-pending.md), que se mantiene como registro histórico.

## Motivo

Una revisión de estructura del proyecto (2026-08-02) detectó que el fichero ya contenía contenido real y consolidado pese a que `CLAUDE.md` y `decisions/0003` seguían describiéndolo como pendiente. Se reconcilia la documentación con el estado real del repositorio.
