# 0001 - Estructura documental

## Decisión

El proyecto se organiza como documentación Markdown normalizada bajo `docs/`.

## Estructura

```text
README.md
CLAUDE.md
docs/
  devices.md
  systems.md
  software.md
  distributions.md
  system-paths.md
decisions/
prompts/
references/
tools/
.claude/
```

## Motivo

Separar documentos finales, instrucciones para Claude Code, decisiones y prompts reutilizables.
