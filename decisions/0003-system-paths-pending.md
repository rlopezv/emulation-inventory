# 0003 - system-paths.md pendiente de definición

## Decisión

Se creará `docs/system-paths.md` para documentar rutas de sistemas por firmware/frontend, pero su estructura queda pendiente.

## Motivo

Las rutas de ROMs, BIOS, saves, states, `gamelist.xml` y media dependen del firmware, frontend, launcher, estructura de carpetas y configuración del usuario.

No deben mezclarse con `docs/distributions.md`.
