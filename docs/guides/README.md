# Guías

Índice de las guías de instalación y configuración del repositorio, organizadas por área. Cada subcarpeta tiene su propio índice con el detalle de cada guía.

| Área | Contenido | Índice |
| --- | --- | --- |
| CFW / OS | Instalación paso a paso del firmware/OS marcado `Recomendado`/`Verificado` en `docs/distributions.md` | [cfw/README.md](cfw/README.md) |
| Apps / Frontends | Configuración de frontends y emuladores standalone sobre un CFW ya instalado | [apps/README.md](apps/README.md) |
| Romsets | Preparación de romsets por tipo de fuente (cartucho, óptico, arcade, microcomputers) y workflow end-to-end | [romsets/README.md](romsets/README.md) |
| Herramientas | Uso detallado (comandos, parámetros) de las herramientas de `docs/tools.md`, por fase del workflow de romsets | [tools/README.md](tools/README.md) |
| BIOS | Volcado, verificación, organización y despliegue de BIOS/firmware | [bios.md](bios.md) |
| Perfiles de hardware | Rendimiento curado por juego para hardware trabajando al límite | [hardware-profiles/README.md](hardware-profiles/README.md) |

## Flujo completo para un dispositivo

Para secuenciar todas estas piezas de principio a fin sobre un dispositivo concreto (qué instalar, en qué orden, y dónde encaja cada guía), ver [device-setup.md](device-setup.md).
