# Herramientas

Catálogo de herramientas de PC para gestión, validación, conversión y scraping de romsets/DATs. Distinto de `docs/software.md`, que cubre software instalado *en un dispositivo* (CFW, OS, frontends, launchers); estas herramientas no se instalan en los handhelds/SBC del inventario, sino que se usan en el ordenador para preparar las colecciones antes de desplegarlas en `data/roms/`.

## Convenciones

### Categoría

* Configuración
* Scraping
* Validación
* Gestión
* Librerías
* Volcado
* Conversión
* Ports
* Servicios
* Parcheo

### Estado

* Activo
* Mantenimiento
* Histórico
* Descontinuado
* Experimental

### Nivel de usuario requerido

* **Básico** — GUI simple, sin configuración previa ni conocimiento del dominio para un uso correcto.
* **Intermedio** — GUI con configuración no trivial, o CLI sencilla con pocos flags.
* **Avanzado** — CLI con sintaxis/flags compleja, requiere compilar desde código fuente, o conocimiento técnico profundo del dominio (formatos, hashes, estructura interna) para usarla correctamente.
