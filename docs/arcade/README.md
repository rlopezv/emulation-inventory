# Arcade

Colecciones **Bartop Curated** y referencia de emulación arcade.

Los catálogos están orientados a bartop horizontal con controles arcade: juegos rápidos, rejugables y adecuados para sesiones cortas. No son fullsets ni colecciones de preservación.

Los catálogos se generan con el prompt `prompts/arcade_games.md`.

## Formato de los catálogos

Cada catálogo contiene:

- Tabla principal con todos los juegos curados
- Tabla de juegos eliminados con motivo
- Tabla de juegos añadidos con motivo
- Tabla de estadísticas (originales − eliminados + añadidos = total final)

Columnas de la tabla principal:

| Campo | Valores |
| --- | --- |
| Tier | S, A, B |
| Arcade | S, A |
| Rot | H, V, HV |
| Ctrl | 2B, 3B, 6B, LG, WHEEL |
| Players | 1P, 2P, 3P, 4P |

### Tier

- **S** — Imprescindible; juego de referencia del sistema
- **A** — Muy recomendable; título sólido y rejugable
- **B** — Recomendable con matices; válido para colección curada

### Arcade (aptitud bartop)

- **S** — Ideal para bartop; encaja perfectamente con controles arcade
- **A** — Funciona bien en bartop con alguna concesión de control

### Rot

- **H** — Horizontal (landscape)
- **V** — Vertical (portrait)
- **HV** — Compatible con ambas orientaciones

### Ctrl

- **2B** — 2 botones
- **3B** — 3 botones
- **6B** — 6 botones
- **LG** — Light Gun
- **WHEEL** — Volante

### Players

- **1P** — 1 jugador
- **2P** — 2 jugadores simultáneos
- **3P** — 3 jugadores simultáneos
- **4P** — 4 jugadores simultáneos
